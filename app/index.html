🔑 Autenticazione & Chiavi per la Pubblicazione

            
          


          

            
📖 Guida semplice: servono chiavi o account per pubblicare?

            

              

                

                  🎵 BetterLyrics / Unison
                  Chiave automatica o importabile
                

                
    
                  
  • Non serve account email/password. Unison usa una chiave personale salvata sul tuo PC.
    • 
                  
  • Sei nuovo? Al primo invio MetroSync crea la chiave da solo (o premi 🔄 Nuova Chiave). Ricordati di premere 📤 Esporta Backup!
    • 
                  
  • Usi già Better Lyrics sul browser? Opzioni estensione → Identity → Export Identity (o unison.betterlyrics.org) → carica il .json qui con 📥 Importa JSON / PEM.
    • 
                  
  • Bearer Token: quasi mai necessario (solo server o proxy privati protetti).
    • 
                

              

              

                

                  🚀 LRCLIB
                  Nessuna chiave richiesta
                

                
    
                  
  • Non serve nessun account e nessuna API key per pubblicare su lrclib.net.
    • 
                  
  • Come funziona? Premendo PUBBLICA LRCLIB, MetroSync risolve automaticamente il PoW Challenge in pochi secondi.
    • 
                  
  • Token o URL diversi: solo per server LRCLIB privati oppure se possiedi già un X-Publish-Token manuale.
    •
